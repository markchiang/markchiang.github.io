Android 手機使用方式

1. 建議用 Chrome 開啟。若直接開本機 html 被擋，請把這個檔案上傳到 GitHub Pages、Netlify Drop、CodePen 或任何 HTTPS 靜態網頁空間。

2. 第一次按「開始偵測」時，請允許 Camera 權限。

3. 若出現 Permission denied：Chrome 網址列左側圖示 → Site settings → Camera → Allow；或 Android 設定 → Apps → Chrome → Permissions → Camera → Allow。

4. 不開手電筒，所以環境太暗或手指蓋太緊時訊號會弱；這是設計限制。
